# 🧠 MindMate AI

MindMate AI is an AI-powered mental wellness companion designed to help users understand and track their emotions and maintain better mental wellbeing.

## ✨ Features

- 💬 AI Mental Wellness Chat
- 😊 Mood Tracking
- 📊 Weekly Mood Analysis
- 🧠 AI Wellness Insights
- 🔥 Mood Tracking Streak
- 📔 Personal Journal
- 🚨 Emergency Support
- 🔐 User Authentication
- ⚡ Real-time Backend with Convex

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Convex
- Convex Auth

### AI
- AI-powered conversational assistant

### Other
- Lucide React
- REST/API integrations
